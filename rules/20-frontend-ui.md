# rules/20 · 前端界面规范（视觉质量是验收项）

> **页面"能显示"不算完成，"好看且好用"才算完成。** 本页 12 条自查全部通过，才能提交该模块。
> 不做"后台管理系统"观感：这是一个**演播厅**，用户是观众，也是可以随时开口的嘉宾。

---

## 1. 设计基调

| 项 | 规定 |
| --- | --- |
| 主题 | 深色沉浸式（"演播厅"），非纯黑；信息密度中等，留白充分 |
| 背景层级 | `--bg` `#0B0E13` → `--surface` `#12161D` → `--card` `#171C24` → `--card-hover` `#1D2330` |
| 文字 | 主 `#E6EAF2` / 次 `#A8B0BF` / 弱 `#6F7787`；**禁止**纯 `#000` / `#FFF` |
| 席位三色 | 战略顾问 `#E0A03A`(amber) · 行业分析师 `#2FB6A8`(teal) · 技术专家 `#7C8CF8`(indigo) · 主持 `#8A93A6`(slate) · 你 `#4ADE80`(emerald) |
| 分隔线 | `1px solid rgba(255,255,255,.07)`；不用 `#ccc` 硬边框 |
| 强调色 | 只允许上述席位色 + 一个中性主色，**全站主色不超过 2 种** |

## 2. 设计令牌（必须用变量，不许写魔法值）

```css
/* styles/tokens.css —— 只允许在这里出现具体数值 */
--space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px; --space-5:24px; --space-6:32px; --space-7:48px;
--text-xs:12px; --text-sm:13px; --text-md:15px; --text-lg:17px; --text-xl:20px; --text-2xl:28px;
--leading-tight:1.35; --leading-normal:1.6; --leading-loose:1.75;
--radius-sm:6px; --radius-md:10px; --radius-lg:14px; --radius-pill:999px;
--shadow-1:0 1px 2px rgba(0,0,0,.28);
--shadow-2:0 6px 18px rgba(0,0,0,.32);
--shadow-3:0 18px 48px rgba(0,0,0,.42);
--ease:cubic-bezier(.2,.8,.2,1); --dur-fast:120ms; --dur-base:200ms; --dur-slow:240ms;
```

- 组件里出现 `padding: 13px`、`border-radius: 7px` 这类值即视为违规（先在 tokens 加变量）。
- 允许的行内变量：只在 `v-bind` 动态色（如席位色）时使用。

## 3. 排版

- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif`；等宽用于 token/耗时：`ui-monospace, "SFMono-Regular", Consolas`。
- 正文 15px / 1.7；讨论流最大行宽 **720px**（中文长文可读性）；标题 20/28，字重 600。
- 中文与数字/英文之间加空格："第 2 回合"、"SSE 连接中断"、"38%"。
- 段落不首行缩进；列表用紧凑间距；不使用全大写英文短语。

## 4. 组件质感（每处都要有"手感"）

| 要求 | 具体 |
| --- | --- |
| 四态 | `hover`（背景提亮 + 边框增强）、`active`（缩放 .98 或位移 1px）、`focus-visible`（2px 外环，色 = 席位色）、`disabled`（透明度 .45，**不改变布局**） |
| 过渡 | 背景/边框/位移统一 `var(--dur-fast) var(--ease)`；禁止 `transition: all` |
| 按钮 | 主按钮实心 + 次按钮描边 + 文字按钮；同屏主按钮 **≤1 个** |
| 卡片 | `--radius-md` + `--shadow-1`，hover 抬升 1px；**禁止**在卡片上叠三层阴影 |
| 输入框 | 聚焦时边框变席位色 + 外环；支持 `Enter` 发送、`Shift+Enter` 换行；字数超限时就地提示 |
| 图标 | 只用内联 SVG（16/20px，`stroke=currentColor`）；**禁止 emoji 当图标** |
| 头像 | 圆形 + 席位色描边 + 姓名首字；不加载外部图片 |
| 标记 | 状态点 6px；「第 N 回合」用 pill 形徽标；引用用 `↩` + 被引用者色 |

## 5. 四态与边界态（缺一不可）

1. **加载**：骨架屏（形状与真实内容一致），不用居中转圈。
2. **空态**：一句解释 + 一个动作（「还没有圆桌，发起第一场？」），配一个线性小图。
3. **错误**：说明原因 + 下一步按钮（重试/返回），不打裸 `Error` 文本。
4. **正常**：含 0 席位、超长人名（截断 + title）、100+ 消息（滚动容器）、断网（顶部条）等边界。

## 6. 布局与滚动（硬约束）

- 根容器 `height: 100dvh; overflow: hidden` —— **不允许整页滚动**。
- 圆桌页三区各自滚动：席位栏 / 讨论流 / 轨迹栏，互不影响；输入区固定底部。
- 讨论流：用户停在底部时自动跟随；上滑阅读时不强制滚动，显示「有 N 条新发言 ↓」浮标。
- 断点：≥1920（席位 260 / 流限宽 960 居中 / 轨迹 360）；1280–1919（240 / auto / 320）；768–1279（两栏 + 轨迹抽屉）；<768（单栏 + 顶部席位横滑 + 轨迹全屏抽屉）。
- 任何断点下**不得出现横向滚动条**；`resize` 时不跳动。

## 7. 流式渲染表现

- 消息卡先占位（骨架 + 席位色左边条），首 token 到达后逐字显示，速度 30–50 字/秒，用 `requestAnimationFrame` 合批。
- 生成中显示光标（1s 呼吸）；结束后光标消失，尾部淡出 120ms。
- 多路并行时**固定槽位**（按 `message.start` 顺序），后到的不插队，避免跳动。
- 失败卡片：红色细边 + 「发言中断 · 重试」，保留已生成内容，不整块替换成错误。
- 新发言提示浮标：`position: sticky` 底部居中，点击回到底部。

## 8. 动效（只有三处）

1. 席位卡生成：淡入 + 上移 8px，240ms；
2. 流式光标：1s 呼吸；
3. 新消息浮标：120ms 淡入。

`@media (prefers-reduced-motion: reduce)` 下全部关闭。禁止：视差、粒子、大面积渐变位移。

## 9. 禁止清单

- ❌ emoji 当图标；❌ 纯黑背景 + 纯白文字；❌ 超过 2 种主色；❌ 三层以上阴影；
- ❌ 组件内联 `style="..."` 写布局（仅允许动态色）；❌ 魔法数值；
- ❌ 英文按钮/占位（`Submit`、`No data`）；❌ 默认 `<button>` 外观；
- ❌ 页面出现"后台表格 + 表单堆叠"观感；❌ `alert()` / `confirm()` 原生弹窗。

## 10. 美化自查 12 条（提交前逐条打勾）

- [ ] 1. 视觉有明确层级：背景 / 面板 / 卡片三级底色可辨
- [ ] 2. 所有间距来自 `--space-*`，无 13px、7px 之类魔法值
- [ ] 3. 正文对比度 ≥ 4.5:1，大字 ≥ 3:1（用 DevTools 取样）
- [ ] 4. 三个角色在席位栏、消息卡、轨迹三处颜色一致且可辨
- [ ] 5. 每个可交互元素都有 hover + focus-visible 两态
- [ ] 6. 四个状态齐全：骨架 / 空态 / 错误 / 正常
- [ ] 7. 长文本截断正确（2 行 + 省略号 + title）
- [ ] 8. 四档断点各截一张图，均无横向滚动条
- [ ] 9. 圆桌页三区独立滚动，输入区不随滚动移动
- [ ] 10. 流式输出不抖动、不跳行、不抢滚动
- [ ] 11. 界面无英文残留（含 placeholder、aria-label、空态）
- [ ] 12. 键盘可完成主流程：Tab 到输入框 → 输入 → Enter 发送 → Esc 关弹层
